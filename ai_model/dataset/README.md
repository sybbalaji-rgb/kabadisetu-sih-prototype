# KabadiSetu E-Waste Training & Benchmark Dataset
### SIH26229 – E-Waste Material Taxonomy

This directory contains the dataset catalog and annotation guidelines for training and evaluating scrap classification models under Central Pollution Control Board (CPCB) standards.

## Supported Classes
1. **cables**: Copper wiring bundles, PVC-insulated power cords, Ethernet cables, automotive harnesses.
2. **batteries**: Lithium-ion laptop/mobile packs, sealed lead-acid (SLA), NiMH cells.
3. **pcb**: FR-4 motherboards, RAM modules, consumer electronic daughter boards, power SMPS.
4. **panels**: LCD laptop displays, CRT glass assemblies, television monitors, optical diffusers.
5. **motors**: Stators, copper coil windings, fractional horsepower compressor units, transformers.
6. **plastics**: Rigid ABS enclosures, polycarbonate computer mice shells, keyboard casings.

## Format
Annotations are structured in standard COCO and YOLO vision formats with class IDs 0 through 5.
